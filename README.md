# LOOP

Tus series, a tu ritmo.

LOOP es una aplicación para Android que te permite organizar tus series y anime, registrar los episodios que ves y compartir tu experiencia con amigos.

## Descargar

[Visitar la página de LOOP](https://loop-tvapp.github.io/loop/)

[Descargar el APK más reciente](https://github.com/loop-tvapp/loop/releases/latest/download/LOOP.apk)

## Funciones

- Listas de series: por ver, viendo, en pausa y completadas.
- Seguimiento de episodios y progreso.
- Favoritos, estadísticas y logros.
- Publicaciones y Daily Loops.
- Listas cooperativas para ver series en compañía.
- Widget para marcar episodios desde la pantalla de inicio.

LOOP permite llevar el seguimiento de tus series. No reproduce ni distribuye episodios.
